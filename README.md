# Управление товарными остатками

Публичный браузерный инструмент для ABC/XYZ-анализа, точки заказа и поиска неликвидов.

## Как пользоваться

1. Откройте опубликованную страницу.
2. Загрузите XLSX/CSV, вставьте таблицу или укажите публичную Google Таблицу.
3. Проверьте сопоставление колонок и выберите периоды продаж.
4. Откройте обзор, «К заказу», ABC/XYZ или карточку товара.
5. При необходимости скачайте Excel с позициями к заказу.

## Данные и обмен

Файлы и результаты обрабатываются в браузере и сохраняются только на устройстве пользователя в IndexedDB — локальном хранилище, которое подходит и для крупных выгрузок. Сайт не создаёт общую базу и не передаёт данные другим пользователям.

Чтобы коллега выполнил тот же анализ, передайте ему исходный XLSX/CSV, публичную Google Таблицу или сформированный Excel-отчёт.

Очистка данных сайта в браузере удалит сохранённую локальную загрузку. Кнопка «Новая загрузка» также удаляет локальные данные приложения.

## Публикация

Workflow `.github/workflows/pages.yml` публикует содержимое папки `public` на GitHub Pages после push в ветку `static-github-pages`.

## Ограничения

- нет входа, ролей и общей базы данных;
- email-отправка и серверные заказы отсутствуют;
- ссылка на сайт не содержит чужие загруженные данные;
- публичная Google Таблица должна быть доступна без входа.
