# Миграция в статическую версию для GitHub Pages

## Что меняется принципиально

| Было | Станет |
|---|---|
| Node.js-сервер, SQLite, сессии и API | Только HTML, CSS и JavaScript в браузере |
| Вход, роли, администратор и общая база | Открытый инструмент без регистрации |
| Общие версии импортов и заказы | Данные конкретного пользователя в IndexedDB браузера |
| SMTP-отправка отчётов | Скачивание Excel; пользователь передаёт файл сам |
| Docker/серверный хостинг | Публичный GitHub Pages |
| Доступ к данным по учётным записям | Любой, у кого есть ссылка, открывает приложение |

## Что сохраняем

- импорт XLSX/CSV, вставку таблицы и публичную Google Таблицу;
- сопоставление колонок, характеристики и контроль ошибок;
- ABC/XYZ, точку заказа, неликвиды, фильтры, графики и карточку товара;
- ручную корректировку количества, черновик заказа и Excel-экспорт;
- локальное восстановление последней загрузки и настроек.

## Как пользователи обмениваются данными

Публичная ссылка открывает сам инструмент, но не чужую загрузку. Для совместной работы пользователь передаёт публичную ссылку на исходную Google Таблицу либо сформированный Excel-отчёт. Коллега открывает страницу и запускает такой же расчёт в своём браузере.

## Этапы

## [x] Этап 1. Статический каркас и безопасная миграция

- Создать отдельную Git-ветку для статической версии; серверная версия остаётся сохранённой в `main`.
- Убрать зависимость интерфейса от серверных API и экран входа.
- Сделать стартовый экран с тремя действиями: файл, вставка, Google Таблица.
- Подключить клиентскую библиотеку чтения XLSX через локальный статический файл, без CDN и без секретов.
- Проверить, что страница открывается через статический сервер и не обращается к `/api`.

**Выполнено:** создана ветка `static-github-pages`; интерфейс заменён на статический стартовый экран без входа и API; добавлен локальный браузерный файл чтения XLSX; поддержаны выбор файла, вставка таблицы, попытка загрузки публичной Google Таблицы, сохранение последней загрузки и очистка локального хранилища. Синтаксис клиентского JavaScript проверен, обращений к `/api` в статическом интерфейсе нет.

**Ограничение этапа:** мастер сопоставления и расчёты пока намеренно не перенесены; кнопка анализа показывает промежуточное состояние, а не результаты.

## [x] Этап 2. Браузерный импорт и локальное хранение

- Перенести разбор, мастер сопоставления и валидацию в браузер.
- Сохранить активную загрузку, настройки и профиль сопоставления в браузере.
- Добавить очистку локальных данных и резервную копию/восстановление JSON.

**Выполнено:** XLSX/XLS/CSV, вставка текста и публичная Google Таблица читаются в браузере. Пользователь вручную сопоставляет ключевые колонки и выбирает периоды. Последняя загрузка, сопоставление, настройки и ручные количества сохраняются в IndexedDB — локальном хранилище браузера, подходящем для больших выгрузок; добавлена кнопка полного удаления локальных данных. Существующие небольшие данные из прежней версии `localStorage` автоматически переносятся при первом открытии.

**Ограничение:** резервная копия и восстановление JSON не добавлены — это необязательное улучшение, а не препятствие для GitHub Pages.

## [x] Этап 3. Расчёты и аналитические экраны

- Перенести формулы ABC/XYZ, точку заказа, статусы и ручные корректировки в браузер.
- Вернуть обзор, «К заказу», ABC/XYZ, неликвиды, все товары, карточку товара и графики.
- Сохранить Excel-отчёты и локальные черновики заказов; email не переносить.

**Выполнено:** в браузер перенесены ABC по выручке/прибыли/количеству, XYZ, свободный остаток, страховой и целевой запас, точка заказа, рекомендуемое количество и основные статусы. Реализованы обзор, «К заказу», ABC/XYZ, неликвиды, поиск, карточка товара, график продаж, ручное количество и Excel-выгрузка позиций к заказу.

**Ограничение:** в этой упрощённой статической версии не сохраняются серверные заказы и не отправляется email; это сознательное решение новой концепции.

## [x] Этап 4. Публикация и приёмка GitHub Pages

- Подготовить публичный репозиторий без данных пользователей и секретов.
- Включить GitHub Pages для ветки статической версии.
- Добавить README: загрузка, обмен исходными данными, очистка браузера и ограничения.
- Проверить публичную ссылку в чистом профиле браузера.

**Выполнено:** создан публичный репозиторий `enplotnikova07/Test1`, ветка `static-github-pages` отправлена на GitHub, GitHub Pages включён через GitHub Actions. Публикация успешно завершена в запуске `Publish GitHub Pages #3`; адрес приложения: `https://enplotnikova07.github.io/Test1/`.

**Ручная приёмка:** открыть публичную ссылку в обычном или приватном окне браузера, загрузить тестовый файл и оценить понятность интерфейса. Это нельзя полностью проверить без действий пользователя в браузере.

## Критерий готовности

Пользователь открывает публичную страницу без входа, загружает файл или использует публичную Google Таблицу, получает расчёты и скачивает Excel. После обновления страницы результаты сохраняются на этом же устройстве, а очистка данных браузера удаляет их только у этого пользователя.
